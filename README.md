# SteamPY CDKey 价格订阅

Tampermonkey 用户脚本，当前版本 1.3.1。

## 安装

安装 Tampermonkey，新建脚本，将 [steampy.user.js](steampy.user.js) 的完整内容覆盖进去并保存，再刷新 SteamPY。更新时覆盖原脚本，保留订阅和提醒配置。

## 功能

- 游戏详情页订阅并设置人民币心理价，严格低于心理价时提醒。
- SteamPY 全站显示订阅列表和立即检查入口。
- 列表支持滚动、搜索、显示订阅总数、打开商品和取消订阅。
- 每五分钟检查所有地区的订阅；必要时通过同源后台详情页读取网站报价。
- 浏览器通知与可选邮件提醒独立工作，未配置邮箱时跳过邮件。
- 持续低于目标价期间各渠道提醒一次，价格恢复后再次跌破会重新提醒。

## 浏览器通知

点击“开启浏览器通知”并允许权限，用“测试通知”检查显示效果。消息格式为：

> SteamPY上游戏名已出现价格为¥99.00的cdKey，请尽快查看商品链接

点击通知可打开商品。系统勿扰模式可能隐藏通知。

## 可选邮件接口

自行部署 HTTPS 邮件转发服务，在“邮件设置”填写接口地址、收件邮箱和独立 Bearer token。浏览器通过 POST 发送 JSON 字段：to、subject、text、gameId、area、price、target。服务应验证口令、限制收件人与频率，并在接受发送任务后返回 2xx。SMTP 密码或邮件服务商 API Key 只保留在服务器端。

此仓库不提供公共邮件服务，不包含个人接口地址、账号、口令或订阅数据。用户设置存放在 Tampermonkey 存储中。

## 限制与验证

需保持至少一个 SteamPY 页面运行；关闭浏览器、休眠、后台节流会中断或延迟监控。后台详情页加载失败、登录失效、验证码或网站结构变化会导致检查失败，可在订阅列表查看错误。脚本不绕过验证码。

报价按网站返回的单价升序列表读取有库存商品，依赖网站排序契约；不含额外手续费，请核对地区、版本及实际结算金额。历史成交价功能已移除。

已通过 JavaScript 语法检查及模拟 DOM 下 150 条订阅显示、搜索测试；全站后台加载方案尚未完成真实网站端到端验证。
